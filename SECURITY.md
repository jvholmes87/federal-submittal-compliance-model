# Sensitive Information and Security Reporting

This repository is intended to contain only sanitized public research material.

## Do not open a public issue for sensitive material

If you believe the repository exposes non-public operational information, controlled unclassified information, credentials, personal contact information, contract identifiers, internal links, or another sensitive artifact, do not reproduce that material in a public issue or pull request.

Use GitHub's private vulnerability-reporting feature if it is enabled. If it is not available, contact the repository owner through a non-public contact method listed on the owner's GitHub profile and provide only the minimum information necessary to identify the affected file or commit.

## Scope

Examples of information that should not appear here include:

- Project, task-order, contract, building, installation, unit, contractor, or personnel identifiers
- Private correspondence, screenshots, reviewer comments, or government forms
- Raw operational datasets or company financial information
- Credentials, API keys, tokens, passwords, or private Drive links
- Controlled, classified, export-controlled, or otherwise restricted government information

The repository owner may remove or rewrite affected Git history when necessary to protect sensitive information.
